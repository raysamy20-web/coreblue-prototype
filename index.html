Describe an operating change or problem

CoreBlue turns the report into a clear, evidence-backed task. A qualified engineer must approve changes before operation.

Check task

Why it matters: Sensor and interlock signals can stop material flow or cause unsafe conditions. Verify the signal path before changing drive or PLC settings.

Checks to perform
  • Inspect the photo-eye lens, alignment, cable, and power supply.
  • Compare the HMI status with the PLC input and drive stop condition.
  • Review fault and event timestamps before and during a stop.
  • Confirm the interlock purpose with the responsible controls engineer.

Complete when: The cause is recorded, the signal path is tested, the correction is approved, and the decision ledger is updated.

Evidence: installed sensor interlock, CompactLogix-to-PowerFlex network control record.
